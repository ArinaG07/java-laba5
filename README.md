# Лабораторная работа № 5. Stream API, Gson и Lombok

**ФИО автора:** Гуляева Арина Евгеньевна

**Группа:** ФИТ-251

## Описание
Приложение читает данные о посетителях библиотеки из файла `data/books.json` с помощью библиотеки **Gson**.
Классы данных (`Book`, `Visitor`, `SmsMessage`) используют аннотации **Lombok** для генерации геттеров, сеттеров и `toString()`.
Все задания по обработке данных выполнены с помощью **Stream API** (фильтрация, сортировка, группировка, вычисление среднего).

## Команды для сборки и запуска
1. Сборка проекта:
   `./mvnw clean package` (для Windows: `mvnw.cmd clean package`)
2. Запуск приложения:
   `java -jar target/java-lab5-1.0-SNAPSHOT.jar`
